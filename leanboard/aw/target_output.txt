1. The real argument: a terminating success condition
============================================================================
  A finite-object search DECIDES. The SAT encoder returns SAT or UNSAT.
  The 1296-grid enumeration finishes. You know when you are done, and you
  know when you have failed.

  An existence-argument search has no such condition. That is precisely
  why both elaborate prompts in this series had to manufacture one:

    CDC       'Spend at least 8 hours on this before even thinking of
              returning or giving up.'  -- a FLOOR, not a bound
    CDC       'Do not return a reduction, partial result, isolated missing
              lemma, best-effort summary'
    Nevanlinna  three forbidden sentences, including 'no counterexample
              was found'

  Those instructions exist to SUBSTITUTE for a missing stopping condition.
  Neither prompt bounds effort from above, because neither CAN: nothing in
  the task says when the search is over.

  On a constrained budget the unbounded search is the thing you cannot
  afford. Nevanlinna: 7h14m, ~1.02M tokens, and the core still unreached
  by any outside auditor. SSUF: four sentences.
  PASS  the two artifacts with no stopping condition are the two with manufactured
        floors and output bans
  PASS  the finite-object artifacts needed neither   [the encoder terminates; nothing has to forbid it from giving up]

2. The search IS its own control
============================================================================
  Arm AT named the control -- run the apparatus on a case with a known
  answer -- as the one domain-independent feature separating the verified
  artifacts from the unverified ones. For a finite-object search it comes
  FREE, because the instrument is a decision procedure:

    Chow LaTeX  'the same encoder returns UNSAT at n = 3 ... agreeing with
                the verification reported in the paper'
    Preprint    exhaustive audits at ranks 3 and 4, returning 0
                counterexamples where none should exist

  You do not have to ADD a control. Running the same encoder one parameter
  lower is the control, and it costs one run.
  PASS  audit surface, control and budget are three faces of one property

3. Failure is cheap and informative, not expensive and mute
============================================================================
  finite-object search fails as   : a definite negative on a defined space
                                    -> tells you where not to look
  existence-argument search fails : unbounded spend, no verdict
                                    -> tells you nothing

  The preprint's audits are the clearest case: 4,358,045 rank-4 instances
  and 1,120,230 on K_6 returning ZERO counterexamples became Theorem 1.5,
  a published result. A NULL RESULT FROM A FINITE SEARCH IS A THEOREM.
  A null result from an existence-argument search is a bill.
  PASS  the null of a finite search is publishable   [Theorem 1.5 is exactly such a null]

6. The target-selection rule both successes actually used
============================================================================
  Neither success picked a famous problem. Both picked a PARAMETRIZED
  universal claim and attacked at the smallest parameter above the
  verified boundary:

    Chow C(3)   Chow verified n = 3 over ALL matroids on nine elements.
                Both counterexamples are at n = 4.
    Goemans     C = 1 for all instances. The counterexample is seven
                vertices, three terminals, eight routings.

  That is not a coincidence. The minimal parameter above the verified
  boundary is:
    - the cheapest place a finite search can live;
    - the only place an exhaustive control is affordable;
    - where the residual open region is thinnest, so anything there is new;
    - and small enough that the write-up is hand-checkable, which is what
      made both artifacts verify in one sitting.

  RULE. Take a conjecture of the form 'for all instances of size n, P'.
  Find the largest n already verified exhaustively. Attack n+1. If the
  search returns UNSAT, that is a theorem extending the verified boundary;
  if it returns SAT, that is a counterexample. BOTH OUTCOMES ARE RESULTS.
  PASS  the rule is read off both successes rather than proposed
  PASS  the rule has no losing branch   [UNSAT extends the boundary, SAT refutes the conjecture]

7. What this does NOT get you
============================================================================
  - It will not resolve a famous open problem. Those are famous because
    no small parameter settles them.
  - It cannot reach a universal theorem, per arm AV: shipping a finite
    object is available exactly when the target is an existence claim.
  - It does nothing for the SIGNIFICANCE claim (arm AV): 'previously open'
    stays a literature question the certificate cannot answer.
  - And the corpus says 122 of 178 construction-refuted entries sit at
    `unreviewed`. A checkable artifact is not the same as a checked one.
  PASS  the limits are stated alongside the recommendation   [122/178 unreviewed]
