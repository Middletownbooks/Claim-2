1. What the CDC prompt does that the Nevanlinna prompt does not
============================================================================
  + definitions pinned in the prompt itself
     'A cycle is a connected 2-regular submultigraph; thus two parallel edges
     form a cycle of length two.' Also loopless, bridge, multiset, exactly
     two occurrences counted with multiplicity, disconnected allowed, the
     edgeless graph.
  + an explicit INSUFFICIENCY list (7 named near-misses)
     special classes; covers with edges covered other than twice; bounded-length
     or prescribed-cycle variants; reduction to another unproved conjecture;
     computational verification to a fixed size; counterexamples without a
     nonexistence certificate; partial progress not implying the statement.
  + a domain-specific ADVERSARIAL CHECKLIST (7 named failure modes)
     exact-two multiplicity; repeated-edge closed trails masquerading as cycles;
     parallel-edge 2-cycles; disconnected graphs; cutvertices; bridges
     introduced by reductions; circular use of an equivalent CDC statement.
  + an anti-circularity guard on reductions
     'A route that ends at a lemma equivalent in strength to the original
     conjecture is not close to completion unless it supplies a genuinely new
     proof of that lemma.' Plus: mark stalled routes BLOCKED, reopen only on
     a materially new mechanism.
  + an approach REGISTRY with forced redistribution
     'Group agents by the mathematical idea, not by superficial wording. If many
     agents converge to one family, redirect some toward underexplored
     formulations.'
  + output-form requirements on agents
     'Require agents to return concrete lemmas, constructions, equations, or
     counterexamples. Reject status reports, vague optimism, and claims that
     an unproved global compatibility statement is routine.'
  PASS  the CDC prompt is materially more elaborate at the search stage than N   [six mechanisms with no counterpart in the Nevanlinna prompt]

5. The finding this fourth case forces
============================================================================
  SEARCH-STAGE RIGOR AND AUDIT-STAGE RIGOR ARE DIFFERENT INVESTMENTS, AND
  THIS SET SHOWS NO TRADE BETWEEN THEM.

    N    elaborate search prompt, nothing at the output stage   -> core unreached
    CDC  the MOST elaborate search prompt of the four, nothing  -> core unreached
         at the output stage
    P    modest process, four cheap output-stage features       -> core verified
    L    modest process, four cheap output-stage features       -> core verified

  The CDC prompt is the strongest counterexample available to the idea that
  a better search prompt yields a more checkable result. Six mechanisms with
  no counterpart in N -- pinned definitions, an insufficiency list, a
  seven-item adversarial checklist, an anti-circularity guard, an approach
  registry, output-form requirements -- and the artifact is exactly as
  unreachable as the one with none of them.

  What the search-stage work DID buy is real and should be credited: arm AN
  found ZERO mismatches between `minimal_even` and `connected_2regular`
  across 4,860 multigraphs. Pinning the definitions in the prompt closed
  the statement-fidelity surface that arm AK found open on the zeta paper.
  That is a genuine return -- on CORRECTNESS OF THE TARGET, not on
  CHECKABILITY OF THE RESULT.
  PASS  search-stage investment is credited where it paid, and not beyond

6. A side effect worth recording, and its link to arm AR
============================================================================
  The CDC prompt forbids the literature search that would reveal concurrent
  work: 'do not search the public web merely to determine whether CDC is
  open'. The purpose is benchmark hygiene and it is legitimate.

  Its side effect is that the run CANNOT detect that anyone else is on the
  problem. Kintali's paper appeared three days after the 10 July
  announcement, citing it (arm AR). The Nevanlinna prompt takes the
  opposite stance -- 'If you find that my result is already covered by the
  literature, tell me' -- and that instruction is the only thing in any of
  the four prompts that could surface a collision.

  These two goals are in direct tension and no prompt here resolves it:
  contamination control and priority awareness want opposite instructions.
  PASS  the tension is recorded as unresolved rather than adjudicated
